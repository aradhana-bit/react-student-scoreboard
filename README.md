# React Student Scoreboard

## Project Overview

This project is a React-based Student Scoreboard application developed using Vite.
It allows users to manage student data efficiently by adding new students, updating their scores, and displaying pass or fail status dynamically.

## Features

* Display a list of students with their scores
* Update student scores in real time
* Add new students using a form
* Automatic pass/fail status based on marks
* Conditional styling (Green for Pass, Red for Fail)

## Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS (Pure CSS)

## How to Run the Project

1. Clone the repository
2. Install dependencies:

   ```
   npm install
   ```
3. Start the development server:

   ```
   npm run dev
   ```
