# Student Scoreboard

A simple React-based web application to manage student scores.

## 🚀 Features
- Add new students
- Update student scores
- Pass/Fail status (>= 40 = Pass)
- Live statistics:
  - Total students
  - Passed students
  - Average score
- Clean dark UI

## 🛠️ Tech Stack
- React (Vite)
- JavaScript (JSX)
- CSS

## 📦 Installation

```bash
npm install
npm run dev
