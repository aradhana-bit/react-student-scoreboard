## Overview

**React Student Scoreboard** is a dynamic web application built using React and Vite to manage student information and monitor academic performance.

The application allows users to add students, view their scores, and update marks through an interactive interface. Student performance is evaluated automatically, with pass or fail status displayed dynamically based on the obtained scores.

The project focuses on building reusable components, managing application state, and creating responsive user interactions.

## Key Features

- **Student Management:** Add new students through an interactive form.
- **Score Tracking:** Display student records along with their marks.
- **Dynamic Score Updates:** Modify student scores and reflect changes instantly.
- **Automatic Evaluation:** Determine pass or fail status based on student scores.
- **Conditional Styling:** Visually distinguish passing and failing students.
- **Component-Based Structure:** Organize the application into reusable React components.

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/aradhana-bit/react-student-scoreboard.git
```

**2. Navigate to the project directory**

```bash
cd react-student-scoreboard
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
